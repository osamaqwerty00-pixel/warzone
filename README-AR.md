# War Zone LAN — تطبيق أندرويد بسيرفر مدمج

التطبيق يشغّل سيرفر الغرف المحلية بداخله تلقائياً، فيستطيع المضيف أن يفتح التطبيق ويضغط
«غرفة محلية ← إنشاء غرفة» فتعمل بدون إنترنت. الأصدقاء لا يثبّتون شيئاً: يفتحون العنوان الظاهر
في الغرفة (مثل http://192.168.1.5:8080) في متصفح جوالهم ثم «انضمام».

## قبل البناء (مهم)
اللعبة تحتاج ملفين لتعمل بدون إنترنت. ضعهما في `app/src/main/assets/www/`:
- three.min.js  ← https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
- peerjs.min.js ← https://cdnjs.cloudflare.com/ajax/libs/peerjs/1.5.4/peerjs.min.js
(إذا بنيت بطريقة GitHub Actions أدناه فيحمّلهما البناء تلقائياً.)

## الطريقة 1 — Android Studio (على الكمبيوتر)
1. ثبّت Android Studio وافتح هذا المجلد.
2. ضع الملفين أعلاه في assets/www.
3. من القائمة: Build ← Build Bundle(s)/APK(s) ← Build APK(s).
4. الملف الناتج: app/build/outputs/apk/debug/app-debug.apk

## الطريقة 2 — GitHub Actions (بدون تثبيت أي شيء)
1. أنشئ مستودعاً جديداً على github.com وارفع كل محتويات هذا المجلد (بما فيها المجلد المخفي .github).
2. ادخل تبويب Actions ← "Build APK" ← Run workflow.
3. بعد دقائق نزّل الملف WarZone-LAN-apk من أسفل صفحة التشغيل (Artifacts).

## التثبيت على الجوال
انقل app-debug.apk للجوال وافتحه، واسمح بالتثبيت من مصدر غير معروف إن طلب ذلك.

## الاستخدام
- المضيف: افتح التطبيق ← غرفة محلية ← إنشاء غرفة. يظهر الكود والـIP داخل الغرفة.
- الأصدقاء: نفس الواي فاي (أو هوت سبوت المضيف) ← يكتبون العنوان في شريط عنوان المتصفح ← غرفة محلية ← انضمام.
- الخروج من التطبيق (رجوع مرتين) يوقف السيرفر.

## ملاحظات
- الدفع (KING PASS) غير مدعوم داخل هذا التطبيق؛ يحتاج سيرفراً عاماً على الإنترنت.
- السيرفر (LanServer.java) اختُبر على الكمبيوتر على بروتوكول اللعبة نفسه، أما بناء التطبيق وتشغيله على الجوال فلم يُجرَّبا بعد.
